# Apache KIE Release Guide

The canonical release documentation and single source of truth for the Apache KIE release procedure is maintained on the Apache KIE community website:

👉 **[Apache KIE Release Procedure](https://kie.apache.org/community/devs/release-procedure)** (hosted in the [`apache/incubator-kie-website`](https://github.com/apache/incubator-kie-website) repository under `docs/community/devs/release-procedure.md`).

It covers who can run a release, the credentials needed, the Jenkins jobs, every release step and troubleshooting.

For the reference of the release scripts in this repository (arguments, environment variables, dry-run), see [`script/release/README.md`](../script/release/README.md).
